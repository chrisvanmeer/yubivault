Certificate Issuance

Generate a cryptographic key inside your YubiKey and upload the attestation chain.

Step 1: Install YubiKey Manager

winget install Yubico.YubiKeyManager
brew install ykman 
# Debian / Ubuntu
sudo apt install yubikey-manager

# Fedora / RHEL
sudo dnf install yubikey-manager

# Arch Linux
sudo pacman -S yubikey-manager

Step 2: Generate Key & Attestation

Select PIV slot and run these exact commands in terminal:

# 1. Generate RSA {{if eq .RSABits 2048}}2048{{else}}3072{{end}} key pair in slot 9a
ykman piv keys generate 9a public.pem -a RSA{{if eq .RSABits 2048}}2048{{else}}3072{{end}}

# 2. Create the Certificate Signing Request (CSR)
ykman piv certificates request 9a public.pem user.csr -s "CN={{.UserIdentity}}"

# 3. Create the hardware attestation certificate
ykman piv keys attest 9a attest.crt

# 4. Export the Yubico Intermediate certificate
ykman piv certificates export f9 intermediate.crt
